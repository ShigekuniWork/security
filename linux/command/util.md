# Linuxでよく使用するコマンド

## 現在のユーザー名表示

```shell
whoami
```

## ユーザーのID情報

```shell
id
```

## 現在のホストシステムの名前を設定または表示

```shell
hostname
```

## オペレーティングシステム名とシステムハードウェアに関する基本情報を表示

```shell
uname -a
```

## ネットワークインターフェースの確認

```shell
ifconfig
```

## ルーティング、ネットワークデバイス、インターフェース、トンネルを表示または操作

```shell
ip
```

## ネットワークステータスの表示

```shell
netstat
```

## ソケットを調査する

```shell
ss
```

## プロセスステータスを表示する

```shell
ps
```

## ログインしているユーザーを表示

```shell
who
```

## 環境変数を表示

```shell
env
```

## ブロックデバイス一覧

```shell
lsblk
```

## USBデバイス一覧

```shell
lsusb
```

## オープンされているファイル一覧

```shell
lsof
```

## PCIデバイス一覧

```shell
lspci
```
